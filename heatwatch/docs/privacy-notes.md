# プライバシー設計メモ

requirements.md の DAT-101〜104 / NFR-106 / §15.2 を実装者向けに要約する。

## 本文の扱い

- 会話本文は **プロセスメモリ上のみ** で扱う（DAT-104）。
- 永続層（SQLite）に保存するのは派生データ（特徴量値・スコア・ラベル時刻・
  評価結果・ベースライン統計量）のみ。本文・実名・引用を保存しない（DAT-103, §8.2）。
- ログ・例外メッセージ・スタックトレース・レポート・通知ペイロード・git 履歴に
  本文を出力しない（NFR-106）。

## 実データの隔離

- エクスポート ZIP と展開物は `~/heatwatch-data/` 等、クラウド同期対象外かつ
  リポジトリ配下でないディレクトリに置く（DAT-101）。
- `.gitignore` で実データ・派生データ・`.env` を除外する（DAT-102）。

## 禁止列（§8.2）

永続スキーマに次を作らない：本文、実名、相手個人の時系列スコア
（`partner_*_score` 相当）、関係性総合スコア。

## センチネル試験（§15.2）

合成メッセージに `HEATWATCH_SENTINEL_7c21` を含めてフル解析を実行したとき、
この文字列が出現してよいのはプロセスメモリのみ。SQLite・ログ・例外トレース・
`reports/`・通知ペイロード・git 管理下の全ファイルに出現してはならない。
`tests/privacy/` にこの試験を置く。
